Subject:
How a B-tree splits a node

View A: search path for key 68

The search compares key 68 with each key of root R. Key 68 is between 60 and 80, thus the search follows child link 4.

View B: median selection

The median is the key at position 3 of the 5 sorted keys. Two keys stay, two keys go to the new node.

View C: median in the parent

Root R puts key 68 at the right of link D and puts link F at the right of key 68. Root R must then split.

Sequence

  1. 1The insert of key 68 starts at root R.
  2. 2Key 68 is between 60 and 80. The search follows child link 4 to leaf D.
  3. 3Leaf D has 4 keys, which is the maximum. The insert puts key 68 in its sorted position. Leaf D then has 5 keys.
  4. 4The split selects the median, key 68. Leaf D keeps keys 62 and 66. New leaf F gets keys 70 and 74.
  5. 5Key 68 and the link to leaf F move up to root R. Root R then has 5 keys and 6 child links.
  6. 6The split selects the median, key 60. Node R keeps keys 20 and 40 with links A, B and C. New node S gets keys 68 and 80 with links D, F and E.
  7. 7Key 60 moves up. Node R has no parent, thus the split makes new root T. Root T has 1 key and 2 child links.
  8. 8The tree now has height 3. All 6 leaves are at one depth. Each node obeys the limits of order 5.

Notes:

  • This sheet uses the definition where the order is the maximum number of child links. Order 5 thus gives 4 keys at most in a node.
  • An internal node with k keys has k + 1 child links. A leaf has no child links.
  • The keys in a node are in sorted order. Each separator key is larger than all keys in its left subtree and smaller than all keys in its right subtree.
  • An insert always adds the new key to a leaf.
  • A node splits only when it gets a fifth key. Leaf D was full, but the tree had 5 free slots in other nodes.
  • A split of 5 keys gives two nodes with 2 keys each. Each half thus has the minimum number of keys.
  • The median moves up and does not stay in the leaf. A B+ tree is different, because it keeps a copy of the median in the leaf.
  • A split continues up the tree while the parent is full. This insert has 2 splits, which is the maximum for height 2.
  • Only a split of the root increases the height. Thus all leaves stay at one depth.
  • This sheet shows the method that inserts the key first and then splits. A different method splits each full node during the search.
  • This insert reads 2 nodes and changes 5 nodes. An insert without a split changes 1 node.
  • After this insert, each node has a free slot. Thus the subsequent insert causes no split.
  • The sheet does not show the records, the disk pages or the locks.
